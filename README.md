# Zwen · 轻量级研究助手

面向 Fedora + Niri / Wayland，Rust + Tauri 2 + Svelte/TypeScript。[仓库](https://github.com/DzIbupro/Zwen) · [当前进度](docs/development-progress.md)

**当前支持用户配置的兼容文本服务、流式多轮问答、停止、历史与本机恢复，以及完整窗口/轻量胶囊。显式选区入口已接入；截图可附加到胶囊草稿并本机保存，配置可选"图片模型"后随提问发送给视觉模型（官方协议合成验证已通过，真实智谱图片调用未验证）。知识整理尚未接入。用户本机智谱glm-4.7-flash已完成一次真实文本调用；真实多轮、停止、真实截图与真实图片调用待验证。**

## 两种窗口

- `show`/直接打开：完整问答、模型设置、历史与知识库。
- `capsule`：480×96逻辑像素左右的小浮窗，默认顶部居中，固定宽度向下扩展到屏幕约55%后内部滚动。
- 同一WebView和草稿，切换窗口保留问答；Niri只调整本应用窗口，不修改系统配置。
- 胶囊“演示”始终明确标注非AI，与发送模型分开；选区入口和今后的截图入口使用胶囊。

## 问答与数据

- 草稿500ms自动保存；发送前保存问题，成功接受后才清空未继续编辑的草稿。
- 继续会话附带至多近期8轮，总正文限256KiB；模型配置改变时阻止旧会话转发，需新建对话。
- 历史每页20条摘要，回答按需读取；支持查看、继续旧会话。
- 流式响应、表格、公式和代码正常展示；断流/HTTP错误保留部分回答，不自动重试或拼接。
- 首片段、过程检查点和终态保存在本机。界面重载可恢复当前进程保留的未保存回答；整个进程重启只能恢复最近成功落盘的部分并标记中断。
- 保存失败保留回答和重试入口，阻止覆盖及退出；正常quit先停止请求并保存。
- 不自动采集当前应用、屏幕或选区。只有明确发送时才把草稿及本会话上下文交给配置的服务。

## 知识库

模型回答下点**收藏到知识库**，问答与当时的截图副本就保存为本机 Markdown（`<数据目录>/notes/<id>.md`，正文即权威）。完整窗口的**知识库**标签页提供中文子串搜索、列表、净化渲染查看、应用内编辑（标题/正文）、**查看原始问答**（跳回来源对话）、两步删除与"重建索引"（外部增删/编辑文件后用它同步索引；不会删除孤儿文件）。收藏不会消费聊天里的截图。AI 自动整理与知识网络尚未实现。

## 本机使用

```bash
./artifacts/zwen show
./artifacts/zwen capsule
./artifacts/zwen screenshot
./artifacts/zwen recover
./artifacts/zwen quit
```

构建产物不提交Git。`recover`重载界面，草稿只保证最后一次成功保存；渲染进程失效时不等于已持久化所有输入。

用户已选择[智谱配置](docs/providers/zhipu.md)：文本`glm-4.7-flash`，图片`glm-4.6v-flash`（模型设置中可选填写）。密钥两种方式任选：

- **推荐：设置页保存一次**——"模型设置"底部粘贴密钥 →"保存密钥"，写入本机系统钥匙环（gnome-keyring），之后每次启动自动使用，界面不显示、不回传密钥；可随时"清除已保存密钥"。
- 或沿用启动环境：在自己的终端运行：

```bash
./scripts/run-with-key.sh
```

输入不回显，只进入应用进程环境；不创建.env文件，不把密钥发进聊天。配置页面仅保存非敏感地址/模型/环境变量名；密钥保存走系统钥匙环，不进数据库。浏览器是界面预览，不会读取密钥或连接模型。

## 选区快捷入口

选中文字后，由Niri快捷键直接调用以下入口；不要先打开终端或点击Zwen再触发，以免原应用撤销选区。可将命令绑定到你尚未占用的按键，程序没有自动改动Niri配置。

```bash
/home/dzibupro/Zwen/Zwen/artifacts/zwen select
/home/dzibupro/Zwen/Zwen/artifacts/zwen explain-selection
/home/dzibupro/Zwen/Zwen/artifacts/zwen translate-selection
```

分别导入原选区、添加解释前缀、添加翻译成中文前缀。读取PRIMARY后才唤出胶囊，附加现有草稿并保存，**不会自动发送**。保持正在运行的Zwen可沿用用户本机启动时提供的模型密钥；冷启动也可导入，未配置密钥则不能发送。

选区限64KiB、读取目标750ms；失败不读普通剪贴板、不模拟复制、不覆盖草稿。PRIMARY只反映其所有者提供的文字，不能保证每个应用支持或证明它是刚选中的内容。当前原生集成使用合成wl-paste验证，实际浏览器/阅读器/终端矩阵仍待确认。

未确认导入遇到界面重载时，先检查草稿再决定重新添加或丢弃；不自动重复。待处理材料只在当前进程RAM，整个进程被强制终止不保证恢复；已成功保存到草稿的内容照常恢复。

## 截图附加草稿

```bash
/home/dzibupro/Zwen/Zwen/artifacts/zwen screenshot
```

触发后会先显示胶囊，再打开 Niri 交互截图界面；选中区域后，截图以缩略图附加到当前草稿，可补问题、删除或重截。**不会自动发送，也不会上传图片。** 在模型设置中填写可选”图片模型”（如 `glm-4.6v-flash`）后，发送问题会把截图按官方协议一起交给视觉模型；留空时发送被禁止，绝不把图片冒充文字发给文本模型。

- 每次截图使用唯一私有路径；只有命令成功、文件出现且 PNG 校验通过才算成功。
- 等待选区期间 **Zwen 窗口会隐藏**，避免遮挡截图区域；结束后胶囊自动回到顶部居中显示缩略图。Niri 里的 Esc 取消无法实时通知 Zwen；**等待期间再按一次快捷键=重新开始截图**（丢弃旧等待）。若 Niri 截图界面还开着就再按，本次等待最迟约 60 秒超时提示；建议先完成或 Esc 关闭选区界面。
- 限制：PNG；单张≤24MiB、≤8192 像素边长且≤10MP；最多 3 张、合计≤48MiB；缩略图最长边 480。发送负载另行限界：单张≤4MiB、≤6000px，必要时自动等比缩小。
- 发送后输入框立即清空；截图在**模型开始回答**时消费。若请求一个字都没生成就失败（如 429 过载、网络错误），问题会自动回到输入框、截图保留——再按一次发送即重试。追问在同一会话内以纯文本进行，历史上下文不回带图片，需要图片时重新截图。
- 图片只保存在本机数据目录；密钥仍只从启动环境读取。真实智谱图片调用尚未验证。
