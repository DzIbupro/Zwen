# 历史跨页批量删除及清空全部

本单元完成用户历史删除剩余范围。支持跨页勾选、全选/取消本页、取消全部勾选；批量删除确认时固定所选ID副本，并显示数量。清空全部有独立按钮，明确提示删除所有分页、不可恢复且草稿/收藏保留；按确认请求被处理时的事务快照执行，不仅处理界面当前20条。

## 状态和存储保护

Journal.delete_history对selected或all在一个Immediate事务里先检查生成中/非法状态再删除，任何错误整批回滚，重复/缺失ID幂等，空选择和非法ID拒绝。单条包装复用同一实现。新main IPC仅接收明确selected{requestIds}或all，unknown字段/混合范围拒绝；测试发现Serde内部标记的unit枚举即使deny_unknown_fields仍忽略多余字段，已用空struct变体All{}修复并加回归，JSON形式仍为kind=all。

原生chat mutex拒绝活动任务或未保存回复期间删除；事务成功后只失效命中的last缓存。只操作turns，草稿/收藏Markdown及来源ID保留。前端成功清理对应详情和勾选，回第一页；失败保留选择/详情。清空后失效通知只包含确认时附着的回复ID，父App再次核对精确ID，避免删除完成时误清新创建的回复。之后创建的问答不属于已结束的删除事务。
