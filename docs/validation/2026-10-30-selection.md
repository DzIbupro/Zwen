# 显式选区导入验证 · 2026-10-30

本轮实现 select / explain-selection / translate-selection，读取PRIMARY后附加草稿并显示胶囊；不自动发送、不读普通剪贴板、不模拟复制、不更改Niri配置。

## 证据

- Rust core/transport共60项通过，新增选区10项：64KiB精确边界/超限、UTF-8/空白/NUL/非零退出、750ms上限、部分输出不算成功、stdout关闭但子进程不退出、继承管道、缺失工具、单槽并发/迟到/确认/退出所有权和CLI动作。
- 前端共45项通过，选区12项：保留旧稿/未保存编辑、重复通知、加载前不消费、重载人工检查、保存/确认失败、超限、dispose、手动重试/丢弃与迟到成功或失败刷新互斥。
- Svelte0错误0警告、前端构建、普通原生构建通过。
- 原生合成3场景通过：冷/热单实例、失败保留、重复调用读完前不聚焦；已消费未确认材料重载后先人工检查，CLI recover实际路由与退出保护；读取中隐藏保持未映射、主动展开保持完整窗口。所有窗口/焦点查询仅针对测试自有进程。
- 既有草稿edit/restore/quit三场景与胶囊几何/上限滚动回归通过。

## 失败先行与修复

1. 重复触发在已有读取时提前activate，原生Niri焦点断言先失败；改为只由第一个读取完成持有激活权，随后通过。
2. 待确认材料能直接quit，恢复场景先退出0但无完成事件；原生退出守卫随后通过。
3. 独立评审发现手动导入/丢弃可被refresh清除busy；三个延迟操作测试先失败，串行化和延后刷新后通过。
4. 独立评审指出迟到完成覆盖收起/展开，按核心窗口交互影响升级为Important；原生隐藏断言先失败，窗口意图token与同一操作锁保护后，隐藏和展开都通过。token独立于材料确认，不因提前确认而失去保护。

## 测试范围

scripts/validate_selection.py用私有PATH中的合成wl-paste严格验证参数，只使用临时数据库与合成文字，不读取/更改真实PRIMARY或CLIPBOARD，不连接模型。无新增系统包；直接依赖libc使用已有锁定缓存版本。

这些结果不证明Firefox/PDF阅读器/终端等真实应用的PRIMARY行为，不是长时间稳定验收；本轮未重新做完整内存压力测试。上轮PSS/RSS结果不可冒充本轮新增链路实测。未确认材料仅在RAM，强制结束进程不能保证恢复；已成功保存到草稿的材料按草稿恢复。
