# 对话内论文阅读与选区提示关闭

用户已确认v2分析可用，本次按反馈收紧界面：取消独立论文侧栏和页面，将阅读能力放到现有对话输入区。分支仍为feat/paper-analysis-v2，未合并或推送主分支。

## 结果

- 输入区“论文阅读”按钮加载内置skill；上传PDF后显示小卡片和可移除附件。空问题可直接发送精读，也可输入本轮问题，通过原有发送按钮提交。
- 分析、停止、追问、历史、收藏和Markdown导出均在普通对话中。新PDF创建独立的来源绑定会话；退出阅读准备普通新对话，不仅切换外观。
- 卡片默认收起长设置与说明；需要时可调整预置要求、查看原文/缺页、选择已导入论文或查看旧版只读记录。文件可提取页数与实际目标服务可见。
- 未发送的论文草稿和自定义要求可在WebView重载后恢复。恢复期间阻止发送，失败保留附件。全窗口可发送的视图以及胶囊均显示论文状态，避免隐式携带资料。
- 主界面选词提示增加有可访问名称的×按钮。此前组件虽声明了onDiscard类型，却没有接收和呈现此回调。现在沿用既有原生acknowledge，关闭提示/操作条并保留草稿；无pending项的错误提示也可关闭。
