# 模型密钥钥匙环保存 · 2026-11-01

环境：Fedora 45，gnome-keyring（`org.freedesktop.secrets` 在用户总线可用），Rust 1.98.1，zbus 5.19.0（复用既有依赖树，未新增第三方 crate）。

## 1. 功能与边界

用户诉求：每次启动都要通过 `run-with-key.sh` 输入密钥；希望在设置页保存一次，之后自动使用。实现为设计文档预留的 Secret Service 路径：

- **设置页新增"模型密钥（可选，保存到系统钥匙环）"**：粘贴密钥 → 保存密钥 → 写入 gnome-keyring 默认集合，条目标签「Zwen 模型密钥」，属性 `{xdg:schema: io.github.dzibupro.zwen, zwen-role: model-key}`，`replace=true` 原子覆盖旧条目；提供"清除已保存密钥"。
- **解析顺序：启动环境优先，钥匙环兜底**。`ZWEN_API_KEY`/自定义环境变量存在时行为与之前完全一致（run-with-key.sh、合成测试不受影响）；环境未提供时自动读取钥匙环。因此"每次必须输密钥"的流程成为可选项。
- **密钥不过 IPC 回传、不进 SQLite、不写日志**：设置页只显示来源（`environment`/`keyring`/未检测到），不显示密钥值；`provider.sqlite3` 仍只存非敏感配置；保存成功后输入框清空。
- 会话方式：Secret Service "plain" 会话，密钥仅经过本用户私有 D-Bus（与 libsecret 无协商时的行为一致）。错误路径：钥匙环不可用/锁定（`keyring_unavailable`）提示解锁；删除若需确认则提示到钥匙环管理器手动删除；非法密钥值（空/超 4096/非 ASCII 图形字符）本地拒绝。
- 前端：`clearSecret` 刷新状态时保留未保存的字段编辑，不丢用户输入。

## 2. 验证

- **真实钥匙环端到端（本机 gnome-keyring，通过应用自身代码）**：`cargo test -p zwen-desktop real_keyring_roundtrip -- --ignored` 通过——写入合成值 `zwen-ring-check-123` → 读回一致 → 删除 → 读取为空。测试值非用户密钥，测试结束即删除，钥匙环无遗留。
- 期间发现并修复协议错误：Secret 结构第 4 字段（content_type）按官方规范是字符串 `s`，首版误用 `au`，DBus 返回 InvalidArgs 后修正。
- Rust：core+transport 79 项、zwen-desktop 单元（含钥匙环校验）通过；前端 59 项（新增保存/清除/来源展示 4 项）、`svelte-check` 0 错误 0 警告、`vite build` 通过。
- 普通二进制重建：SHA256 `cc2d25f0d881fa7c260f5487f648c46a9b47e0f0258598a6b673df51c9e27256`，不含 desktop-smoke。
- **未验证**：含真实密钥的完整发送链路（用户在设置页保存后提问一次即为真实验证）；钥匙环锁定状态下的提示；Wayland 会话中钥匙环提示弹窗的交互；`save_provider` 与 `save_secret` 并发。原生 UI 回归（provider/capsule/selection/chat/screenshot/chat-image）仍待用户退出实例后补跑。

## 3. 安全边界不变项

密钥不进 SQLite/日志/截图/聊天；IPC 只返回来源枚举；`ApiKey` Debug 仍脱敏；错误信息不含密钥内容。`run-with-key.sh` 继续可用且优先。
