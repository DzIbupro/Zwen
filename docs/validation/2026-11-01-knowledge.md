# Markdown 知识库第一单元 · 2026-11-01

环境同前。本单元交付路线图阶段 3 的最小纵向切片：**收藏 → 知识库页（列表/搜索/查看/删除）→ Markdown 文件为权威**。AI 整理与图谱尚未开始。

## 1. 存储设计（与 design.md §3 一致）

- 位置：`<data>/notes/<32位hex id>.md`（正文权威，稳定 ID=文件名）、`<data>/notes/attachments/<id>-<净化文件名>`（笔记附件副本）、`<data>/notes.sqlite3` schema1（**可重建的派生索引**：id/title/created_at/source/model）。
- MD 头部为 front matter（id/created/source/model/title/attachments JSON 数组）；无 front matter 或损坏时整个文件按正文采纳，标题回退"未命名笔记"——不丢内容。
- 写入顺序：临时文件→fsync→原子改名（0600）→索引事务；索引失败回滚删除本笔记文件。**孤儿文件只采纳不删除**（rebuild 从文件重建索引；索引行缺文件则删除行）。删除笔记=删行+删文件（文件已缺失也删行，不留幽灵条目）。
- 边界：正文≤256KiB；标题≤200B；来源≤64B；模型≤200B；每笔记附件≤6 个、单文件≤24MiB；文件名白名单（ASCII 字母数字/汉字/`.`/`-`/`_`，其余转 `_`，去路径分隔）；搜索词≤256B；列表≤200 条按时间倒序。
- 搜索：中文参数化子串（标题 LIKE 转义 `%`/`_`/`\`，正文 `contains`，读文件≤256KiB）。

## 2. UI

- 完整窗口回答区新增**收藏到知识库**（仅真实模型回答、已保存、非生成中可用）：正文=问题+回答结构化 Markdown，来源 `chat`，模型名，当前截图以副本纳入（**聊天附件不消费**，仍可发送）。
- 新"知识库"标签页：搜索框（实时）、列表、点击查看（Markdown 净化渲染）、两步确认删除、"重建索引"按钮。胶囊不加收藏（最小单元）。
