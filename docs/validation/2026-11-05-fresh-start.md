## 实现

- App沿用leave(true)保存与退出守卫，按钮改为现有close图标、36px命中区域，title/aria-label保留“保存并退出”。
- Rust为本进程WebView初始化脚本注入run id。StartupSession仅保存run id/attached标记，不保存用户内容。新进程不自动挂接已保存终态旧回复；ChatController下一次发送conversationId为null。
- 活跃请求、未保存终态优先保留恢复。渲染器重载恢复本进程已附着回复；新对话尚无回复时保留attached:false，重载仍为空白，防止接回旧上下文。首次加载失败后重试仍适用冷启动策略。
