# 划词操作菜单验证记录（2026-11-03）

## 实现

- 开启“自动划词菜单”后监听系统 PRIMARY，稳定200ms后展示候选小胶囊；问一问、翻译、详细解释、其他四入口。来源应用必须提供选区；不是全局鼠标松开钩子，不保证任意页面。排除 Zwen 自身选区；无可用新选区时保留原候选。
- 问一问只添加到草稿；翻译、解释、自定义动作须点击后才请求。独立请求仅使用冻结的本次选区，无旧聊天上下文、无旧截图。已有草稿/截图或请求时提示先处理。
- 设置可编辑提示词、启用/禁用、增删排序自定义动作，{{selection}}插入文字；配置本机SQLite持久化并校验版本，损坏报错不静默重置。默认翻译目标中文，可修改。
- “整理成文档”默认输出 ~/Documents/Zwen，可配置绝对目录。完整且本机已保存的回答才创建知识库笔记和额外Markdown；隐藏暂存文件同步后原子无覆盖导出。失败保留回答/笔记，重试不重复请求AI；同一请求重试复用笔记和已有完整输出。
- 动作版本在点击时冻结并由后端校验，变化则保留选区并要求重新读取。来源和输出元数据绑定requestId，不能把不同请求结果混存。
