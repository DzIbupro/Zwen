## 实现与边界

- 真正的 SQLite 草稿：500ms 自动保存、revision CAS 防止过期写、持久化后重启恢复；保存失败保留输入。
- 关闭窗口、面板退出和第二实例 `quit` 都经过前端保存后再隐藏/退出。无活动实例的 quit 可直接退出；渲染进程无法响应时使用 recover 恢复最后成功保存的状态，不能保证尚未提交的输入。
- 单实例 show/recover/quit；Niri 配置、系统启动器与全局快捷键尚未安装。
- 正常段落、表格、代码、KaTeX 公式。原始 HTML 转义后净化，超大/损坏公式局部回退。图片和外链打开尚未集成。
- 不调用模型、不读屏幕/剪贴板、不自动采集应用上下文。浏览器演示使用 localStorage，桌面使用 SQLite，界面有明确区分。

## 实际桌面与离线证据

Vite/1420服务关闭后，smoke特性构建仍能从内嵌资源启动。脚本 `scripts/validate_desktop.py` 仅操作自己的窗口与临时合成数据库：

- 实际 textarea 输入后自动保存。
- 在追加文字尚未到500ms时触发 native close；保存后约100ms隐藏。
- 再显示、重新加载，表格/公式与完整草稿恢复，revision=2。
- 新进程读取同一临时数据库，恢复成功。
- 新的临时数据库中，第二实例 CLI quit 也保留关闭前追加文字。
- 三组退出0，标准错误为空。最终正常构建不包含 smoke 模块；另验无1420服务启动和第二实例 show/recover/quit 均退出0，主进程正常退出。
