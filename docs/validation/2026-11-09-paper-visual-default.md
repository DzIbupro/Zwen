# 默认20页整页图：公式与图示进入真实请求载荷

用户明确选择Qwen3.7 Flash和百炼官方逐页图像方案，取消直接PDF模型模块、本地OCR及超长文优先扩展。当前仍在feat/paper-analysis-v2，未合并main。

## 原因与修复

旧实现默认readImages=false，图像阅读需手动开启且最多8页，还单独依赖imageModel配置。模型具备多模态能力不代表应用实际传了图片；旧文字路径会在材料中声明图表未读。此次核查确认该默认与路径问题，但未读取用户历史生产库来断言某次真实请求的具体选项。

- 新分析默认readImages=true，所选范围最多20页；无需再单配图片模型。新论文直接使用当前主模型，截图继续沿用原独立图片模型路由。
- Poppler逐页渲染完整PNG，不裁页、无损，最长边由1600提高至3000；图像按物理页排序，提示中逐张映射到PDF页码。纯扫描/矢量图页没有可提取文字也会完整发送。
- 百炼官方maas.aliyuncs.com/dashscope.aliyuncs.com域名且Qwen3.7图像输入时，请求启用vl_high_resolution_images=true。依据[官方高清参数说明](https://help.aliyun.com/en/model-studio/vision)，用于细字与图像细节；其他服务不擅自加专用参数。页图输入路线见[百炼视觉文档](https://docs.bailian.console.aliyun.com/zh/model-studio/vision)。
- 整页图为主要材料；提取文字每轮最多64KiB辅助，省略处明确标记，不能因文字超限漏掉页图或要求模型凭正文重建公式。内置skill要求查看实际附图、核对公式/箭头/图例/数字，不可辨认指出具体页、图、符号，不能泛称所有图表未读。
- 卡片显示实际模型、页范围、完整图片张数。追问按保存范围重新附图，旧图像会话保留开始时的实际turn.model，避免跟随新默认悄悄切模型。
- 旧记录缺readImages字段按false反序列化，旧文字会话保持原样；提供“用整页图重新分析（保留旧记录）”。旧未发送草稿有显式整页图升级提示，新版本主动选择仅文字则保留选择并明确显示未发送图像。

## 大小与生命周期

每页PNG≤5MiB，最长边3000、完整解码预算48MiB；累计编码图像≤12MiB，含上下文的HTTP JSON体≤16MiB。20页、大小、损坏或工具截止超限时明确失败，不静默漏页或缩图。页图在既有可取消worker内生成，整轮渲染最长180秒，每页20秒；图像不存入聊天记录或额外持久文件。渲染全部通过才提交模型请求。

20页是应用范围限制，不保证任意复杂扫描件都能装入体积/服务上下文限制；超出需明确选范围，不能用上传成功冒充全部读取正确。接口/模型理解仍可能出错，真实论文应核对公式和图表。
