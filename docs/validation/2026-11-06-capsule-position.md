# 胶囊默认上移、标题拖动与位置保持

用户已明确要求：胶囊初始位置上移至主窗顶部附近；空态/满态可拖动，后续流式增长不能跳回默认位置；输入、选字、按钮和滚动不受干扰。

## 实现与边界

旧Niri适配在每次resize都重新调用place，强制居中并设置工作区相对Y48；本机旧版默认全局Y91.33。现仅在胶囊唤出时定位到工作区相对Y8，当前桌面与主窗口的小边距一致，全局Y约51.33。面板占区由Niri转换，不硬编码屏幕全局高度；工作区和目标显示器仍取原有focused-output逻辑尺寸。该8px是默认小边距，不动态读取/跟踪用户Niri gaps配置。

标题/品牌和标题空白区域左键按下走Tauri原生start_dragging，只给main窗口增加这一个窗口权限；按钮、可编辑控件、答案选字不触发拖动，右键和双击不触发，避免双击最大化。失败有简短状态提示。使用现有原生接口，无新依赖或常驻轮询。

窗口每次全新唤出回默认位置；同次显示内，ResizeObserver和流式增长只改尺寸，保持合成器当前位置。已有generation和window-intent守卫、宽度/高度上限、全文展开转交与关闭逻辑不改。本机单屏/1.5缩放已测，多显示器与其他合成器不在本单元验收范围。
