# 历史单条删除及整理选择上限反馈

用户明确继续用剩余周额度完成小任务，本轮交付单条删除；历史批量删除/一键清空仍未实现。

## 行为

历史详情增加“删除此记录”，二次确认说明不可恢复且收藏文档仍保留，可取消。生成中/未保存的记录及全局聊天忙时禁止删除，原生chat锁与Journal Immediate事务再次校验。只删除指定request_id，缺失幂等，非法ID拒绝，不创建新迁移或依赖。

事务成功后清理匹配内存last；前端解除当前已删除回复引用并保留草稿。详情清空并刷新，末页为空回前一页；删除期间不交错加载/切换详情；失败保留原记录和可读错误。已收藏Markdown及其原始来源ID保留，来源历史被删后会提示“此记录已删除或暂不可读取”，不会声称原文件必然存在。删除早期会话记录后，后续上下文只包含仍存在的问答。

附带一项小修：知识库第9篇勾选以前静默忽略，现提示每次最多8篇且保留既有选择。取消勾选仅清除本条上限提示，不清掉其他真实错误，不触发模型。不是全选/批处理实现。
