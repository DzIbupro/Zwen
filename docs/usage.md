# 使用指南

## 配置模型

打开「设置 → 模型与凭据」，填写服务地址、模型名称和密钥来源。服务需要兼容 Chat Completions 接口。系统钥匙环可用时，可以在界面中保存密钥；也可由启动环境提供设置中指定名称的环境变量。

文本聊天使用当前文本模型；普通截图提问使用图片模型配置。论文整页阅读直接使用任务开始时保存的当前模型配置，该模型必须支持图片输入。更换模型或服务后请新建对话，避免把旧会话发送到不同服务。

## 论文与追问

点击输入框上方「论文阅读」，选择或拖入单篇 PDF。研究方向输入框位于论文卡片主区域，填写后可在解读中讨论相关用途；阅读关注点和输出结构已有默认值，可以在选项中修改。

页码使用 PDF 的物理页序，从 1 开始。默认图文阅读每次最多选 20 页；遇到请求大小限制时缩小页范围。每轮分析与追问继续使用保存的模型和阅读范围，整页图像用于辨认公式、图表及版面，提取文字作为辅助。

导入只保存在本机，点击发送才提交。分析流式显示，可停止并保留已收到内容；断流后的部分回答不能视为完整报告。原文可交给系统 PDF 阅读器打开核对。

选择仅文字模式时，模型无法看到图像中的公式、图表和扫描内容；不要将此模式的分析当作完整视觉阅读。

## 划词与截图

主窗口适合完整阅读，胶囊适合快速提问。可把 README 中的选区和截图命令绑定到自己的桌面快捷键。

自动划词菜单在「设置 → 划词行为」开启或关闭。选中内容先作为候选材料，确认或选择快捷操作后进入草稿。截图需系统提供 `slurp` 和 `grim`，框选完成后附加到草稿，按 Esc 取消。两者均不会自动发送。

## 收藏、整理与网络

回答下方可收藏到知识库。收藏保存为本机 Markdown，支持搜索、编辑、补充来源与导出。列表有固定高度，可在列表内部滚动。

栏目聚合相关主题，点开后查看细主题。AI 整理可对选中笔记或整轮收藏执行，开启前确认发送范围和模型。开启自动整理表示同意将后续新收藏及有限主题目录发给当前服务；服务配置或授权范围改变后需要重新开启。

知识网络支持栏目与主题层级。拖动旋转、滚轮缩放，悬停或聚焦查看节点名称，点击主题展开笔记。关系线可查看原因和证据；球面的淡经纬线仅用于辅助观察。单次显示数量有限，更多内容可通过搜索查找。

## 设置与数据

设置分为模型与凭据、外观、划词行为、快捷操作。切换分类保留当前面板未保存的输入，请仍按对应保存按钮确认修改。

数据保存在系统应用数据目录。备份前应正常退出应用，并完整复制该目录；不要只复制一个 SQLite 文件而遗漏其关联资料。`ZWEN_DATA_DIR` 可以覆盖数据目录，主要用于隔离测试。不要将其指向其他应用或已有重要数据库目录。
