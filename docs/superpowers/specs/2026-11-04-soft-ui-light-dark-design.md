# Zwen浅深主题与折叠侧栏设计

状态：用户已确认按此实现，另明确两种主题均去掉紫色。用户明确采用本轮三张预览中的第一张，新增“侧栏收窄仅图标”和“设置中选择浅色/深色”。这覆盖旧风格参考中仅浅色背景的限定。现有正式程序efbd8af尚未替换。

## 目的与范围

保持Zwen现有研究/阅读工作流，以统一新拟物视觉降低杂乱感、提高字号和阅读空间。主窗口用于连续问答、历史、知识库与网络；固定宽度胶囊用于快捷任务。原有Rust/Tauri/Svelte/SQLite架构不变，不新增UI框架、远程字体或常驻服务。

## 视觉依据与取舍

采用第一张的文字侧栏工作台，源图保存在docs/design/zwen-light-selected.png。顶部导航与永久窄栏方案已放弃；收起态采用用户明确要求的图标窄栏，不改变所选方案的主布局。

浅色：#e0e5ec/#f0f0f3同色系表面，左上高光、右下灰阴影，炭黑/深灰强调；圆角12–24px。深色：#292d35基底、#30353e表面，#3a414d高光/#1c1f26暗影，文字#e7ebf3、辅助#abb3c3，强调柔白/浅灰。禁止渐变、发光、厚边框；生成图中的光影误差不作为CSS渐变依据。现有原始圆角品牌logo保持不变。

## 布局与交互

- 侧栏展开约180–200px，显示图标和文字；收起约64–72px，仅图标，保留tooltip和可访问名称。折叠按钮始终可见，可键盘操作；收起释放宽度给正文，不留空白。
- 导航复用对话、新对话、历史、知识库、知识网络与设置。收起/主题切换不触发新会话、不丢编辑或材料。既有未保存保护继续生效。
- 主体为可滚动问答阅读区与底部输入区；表格与公式正常呈现，宽表仅自身横向滚动。正文/输入以16px为基线、导航及辅助标签约14px；避免9–11px关键标签。
- 删除英文口号、装饰轨道、欢迎教学卡片及重复宣传说明；演示入口移至次级位置且必须明确非模型。保留必要的错误、未保存、等待/退避与停止反馈。
- 设置增加“外观”，仅浅色、深色两项，立即应用并在本机记住。侧栏展开状态同样记住。主界面、胶囊、历史、知识库、设置、浮动菜单和独立GTK操作条采用一致主题，原生窗口部分按平台实际能力验证。
- 胶囊仍固定480逻辑像素宽，从原始小高度随回复增长到既有上限后内部滚动；不额外放侧栏/大标题，不因主题改变重复激活或重置内容。
- 独立划词条始终独立于胶囊；仅选中文字不弹回复窗，点击命令才打开；可靠锚点near和固定顶中降级行为不变。选图中并排显示只是模式对照。

## 状态与持久化

只在本机保存theme枚举与sidebarCollapsed布尔值，输入严格校验，错误要可见且不触碰模型密钥/用户资料。正式数据与测试临时偏好隔离；启动尽量先应用偏好避免闪白。具体复用已有存储的方式由实施计划在读代码后确定，不新增远程同步。

## 不可退化的功能

原文入稿及末尾光标、关闭快捷任务清理、展开/截图隐藏保留、单次唤出、草稿/附件恢复、首字前重试与取消、部分回复历史保留、自定义文档幂等、知识编辑未保存保护。主题切换仅改变显示，不自动发模型请求或采集应用内容。
