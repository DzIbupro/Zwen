# 快速选区草稿与关闭重置（待实施）

用户要求等额度恢复后再修改。本轮只记录，不改变运行程序。

## 已确认需求

1. 原生操作条点击“问一问Zwen”后，胶囊草稿直接填入原始选中文字。不再添加“选区：”、冒号、额外前导空行；原文字本身的内部格式保留。输入框聚焦，光标置于文字末尾并滚动到可见位置，让用户立即看到已经添加。
2. 用户关闭胶囊后，结束本次快速选区任务；不论未发送、发送失败、停止或已完成，都清理这次任务的草稿和待处理选区/请求恢复标记，下一次划词可直接开始，不再被上次残留草稿挡住。

已保存的问答记录继续保留。本次快速任务应有明确会话所有权，清理范围按本次导入及附带材料处理，不误删其它历史内容。

## 实施时必须区分的动作

用户关闭包括胶囊×、胶囊状态下用户Esc/关闭请求；展开到主窗口、切换显示模式、截图期间临时隐藏不是关闭，不应清空草稿。这是实现上的边界判断，不是追加用户功能。

关闭时若本次快捷请求仍在运行，先停止并沿用已有本机记录保存流程，再重置本次快速任务。停止/失败迟到回调不得把旧问题恢复到已关闭任务或覆盖下一次输入；磁盘错误要明确报错并保留可恢复内容，不能声称保存成功。
