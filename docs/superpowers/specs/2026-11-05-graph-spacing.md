# 知识网络节点与文字避让

用户既有第9项要求：节点与文字不重叠，保持清楚可读。

根因：固定圆环最大260px、30个主题中心间距约54px，小于最大节点直径68px；标签固定y=24会落在最大圆内；展开笔记固定半径90px且不避让其他主题。现按主题数量扩大圆环，节点圆+下方双行标题整体保留184px横向空间，扩展成员寻找确定性的空闲位置；画布包含标签边界。标题按Unicode分行最多两行，每行12字，过长使用省略号，完整值保留在数据、悬停title和aria-label中。标签底色遮住穿过文字的关系线；节点整体命中区覆盖圆与标签间隙。大图有概览/可见放大缩小按钮/滚轮/平移/复位，初始概览密集时需放大阅读。

不改30主题/60关系/12成员的既有限制，不修改收藏、主题或模型调用。验证30主题+12成员无包围盒交叠、完整标题不丢失、可见画布包含标签、已有展开幂等与关系证据行为保持。浏览器用实际KnowledgeGraph组件和合成材料检查，非真实资料/模型或原生真人鼠标验收。
