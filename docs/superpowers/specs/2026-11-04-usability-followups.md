# 2026-11-04 用户试用提出的13项改进

原始要求已获授权：有额度先完成可验证的小批次，接近额度上限记录并暂停。保持既有浅深主题无紫色、轻量、真实模型需用户主动发送、历史不丢失。

1. 收藏回复到知识库：点击后在操作附近给短暂明确反馈，成功才显示已收藏；失败可见，不把自动整理结果当作收藏失败。
2. 主窗口和胶囊删除排版演示、格式预览入口。同步处理内部引用和测试驱动，不能因驱动依赖演示按钮而留下生产入口。
3. 历史缩略项加大，长问题显示更多行/更宽内容；核查后端摘要截断，不能只扩大空卡片。保持整体协调和小窗口滚动。
4. AI整理选择区增加一键全选/取消全选。现有手动整理上限8篇，需设计为分批或明确改变上限，不能静默只选8篇冒充全部。选择不等于上传，原有确认/显式发起仍保留。
5. 空白对话页放较大的Zwen磁场/扫描线logo，参考用户图片的竖向条纹形成品牌轮廓；配“今天想问 Zwen 什么问题？”一句。优先本机SVG/CSS可缩放资源和低资源静态效果，保持原logo识别、浅深主题中性；最终视觉需预览确认，不能擅用紫色或重动画。
6. 小字提高对比与字重、检查两主题清晰度。优先现有本机字体；不随意下载无授权商业字体或声称使用Claude专有字体。
7. 未点击操作条命令时，源应用选区消失即撤销本次候选草稿与操作条，不阻塞下次；去掉手动丢弃和无意义成功/重新读取提示。重点区分候选、用户已点击命令后的冻结材料、普通手写草稿：不能因焦点进入操作条或胶囊后系统选区消失而误删已提交任务或无关草稿。晚到读取/回调不能复活旧候选。
8. 知识库顶层功能（搜索/导出全部/AI整理/重建索引）和下方内容筛选/栏目使用不同视觉层级；同一行文字和按钮垂直对齐，特别AI整理与返回列表。
9. 知识网络节点、边和标签避免重叠；检查标签长度、布局间距、缩放/拖拽和小窗口，真实图谱与合成数据分别说明。
10. 主界面/胶囊截图：窗口完全消失后才开始截图，不能截入退出动画残影。验证原生隐藏完成/合成器呈现，而不是只随意加短延时；取消后状态恢复不丢材料。
11. 用户可见窗口/托盘/页面名称统一“Zwen”，删除“· 学习助手”后缀，原有应用ID/数据目录不改。
12. 区域截图不设用户选区等待时限，直到Esc取消或用户完成；清理孤儿子进程、外部失败仍应报错，不无限阻塞关闭/重启。当前超时具体来自Portal/Niri还是应用需先追踪。
13. 主窗口和胶囊：Enter发送，Shift+Enter换行；中文输入法合成/确认候选不发送，设置/知识编辑器等其他textarea不能误发送问题；原Ctrl+Enter提示移除。
