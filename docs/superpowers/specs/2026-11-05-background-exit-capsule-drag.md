# 最新三项修订：大背景标识、直接退出、胶囊位置与拖动

用户在本轮已部署版本上提出，均待实施。当前账户300分钟约95%，按既有约定只保存，不开始产品修改。优先级高于之前剩余五项，不丢失原有待办。

1. 磁场纹理Logo扩大到接近窗口背景的80%，留出边缘空隙，而非仅中央小图。只保留Zwen图案纹理；去掉其背后可见的黑色背景/阴影/方块轮廓。需按实际字形可见尺寸验收，不能仅把含大留白的SVG容器扩大80%冒充字形变大。浅深主题一致，无动画开销；背景不能挡输入、滚动和按钮。
   - 当前WelcomeMark.svelte有280px/28vh/260px上限，还使用含留白的256px图标亮度遮罩。
   - field-grid为未裁到字形内的独立背景线条，可能形成用户描述的矩形阴影感；需移除/限制到字形内，核对遮罩黑底真正透明，不用黑色填充或投影。
2. 主窗口右上角取消只有少量操作的三点菜单，直接显示“保存并退出”。保留原有保存/进行中状态与退出安全流程。现有条件菜单中的“模型回复”可由侧栏“对话”访问，不能因删除菜单丢掉返回对话途径；以后有更多功能再考虑恢复菜单。
3. 胶囊默认位置上移，与主窗口默认打开时的顶部高度对齐。它只是初始位置，空胶囊和回复已满的胶囊都能按住鼠标左键拖动，在屏幕内自由移动。
   - 采用不妨碍输入、按钮、正文选择及滚轮的拖动区域；优先标题栏/非交互空白，实际拖动须在当前Niri/Wayland上验证，不冒充浏览器样式已支持桌面拖动。
   - 用户拖动后的坐标必须保留：后续流式增长/ResizeObserver不能把胶囊拉回默认锚点，也不能恢复原来的偏下位置。初次唤出如何重设默认、当前会话内保持用户位置应按“默认显示在那里而已”的意图处理。
   - 默认上沿取实际显示器工作区/主窗口基准，避免硬编码屏幕绝对坐标或遮盖顶部任务栏，多屏/缩放单独核对。
