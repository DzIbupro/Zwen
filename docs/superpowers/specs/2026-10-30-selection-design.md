# 显式选区导入（已授权范围的实现细化）

目标：用户从 Niri 快捷键调用 `zwen select`、`zwen explain-selection` 或 `zwen translate-selection`，在焦点转入 Zwen 前读取 PRIMARY，仅附加到现有草稿并显示胶囊，等待用户编辑和发送。沿用既定 Rust/Tauri 架构，不采集前台应用内容、不监听选区、不上传、不改变普通剪贴板。

实现选择：使用已有 wl-clipboard 的 `wl-paste --primary --no-newline --type text`；不使用普通 CLIPBOARD 回退，也不模拟 Ctrl+C。读取最多64KiB，750ms目标超时，丢弃截断、非UTF-8、空白、NUL、非零退出结果；轮询非阻塞管道，失败回收子进程，不输出工具stderr/正文。调度和回收不作硬实时承诺。PRIMARY可能由旧所有者提供，无法据此证明任意应用刚刚划词；跨阅读器支持仍需真机确认。

原生单槽有界收件箱：读取在胶囊激活前完成；忙碌或未确认的材料不被下一次动作覆盖。先订阅事件再读取，避免冷启动丢事件。成功材料自动附加一次并显式保存后确认；读草稿失败不消费材料。渲染器在确认前重载时只显示“待检查选区”，由用户检查草稿后决定重新添加或丢弃，避免自动重复。收件箱仅RAM，退出不承诺恢复未入草稿的材料。

草稿上限256KiB，超限保留原草稿和待导入材料；读取失败仅显示提示。解释/翻译前缀可编辑，中文翻译为实现默认。没有自动发送。失败和待确认状态必须在胶囊内可见，不强制展开大窗口。不给WebView添加读取系统剪贴板权限，只允许读取本次显式动作的收件箱。
