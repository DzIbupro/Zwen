# 历史单条删除最小单元

用户已授权历史删除，本次按剩余周额度先交付单条，批量/清空仍待做。

1. Journal.delete_completed(id)用Immediate事务检查状态，只删除终态指定request_id；生成中拒绝、缺失幂等、非法ID拒绝。临时库验证其他会话/后续上下文/收藏正文、失败回滚和迟到checkpoint不复活。
2. chat.delete_chat_turn使用现有chat锁，活动任务/未保存回复期间拒绝；事务成功后清掉匹配内存last。增加一个main IPC权限，不新增依赖、迁移或模型请求。
3. HistoryController删除锁阻止交错读取，失败保留详情，成功清详情并刷新/回前一页；回调通知App解除当前已删除回复引用，草稿不变。HistoryPanel详情有删除按钮及明确二次确认，生成中与全局忙状态禁用。
4. 前端/Rust回归、临时原生合成历史点击取消/确认/返回聊天与收藏保留验证、独立审查、普通构建后原子安装，保存续接进度。不能拿测试删除用户真实记录，不能声称批量/清空已完成。
