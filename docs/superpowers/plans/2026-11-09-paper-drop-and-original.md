# 对话内PDF拖放与原件核对计划

> 执行方式：superpowers:executing-plans，沿用已授权的文件适配设计和feat/paper-analysis-v2分支。

用户持续授权推进，现有目标是对话内上传并分析论文。本单元补齐本地文件操作，不改模型协议、不请求真实模型、不新增页面。

选择：复用Tauri现有Webview拖放事件和Poppler导入器；HTML FileReader无法可靠提供桌面路径，另建上传服务器也不适合本机应用。原件复用系统PDF阅读器和旧记录已有xdg-open方式。

- [x] 添加拖放控制测试：单个PDF调用原生导入、多文件/非PDF不导入、失败保留原附件、重复与迟到操作不覆盖新状态。
- [x] PaperDraftController串行复用选择器/拖放导入；App仅在完整对话窗口接受拖入，处理中拒绝并提示；拖入只保存本机、显式发送才调用模型。使用Tauri事件而非额外全局路径服务。
- [x] 原生paper_import_pdf复用read_pdf/import验证；注册权限及处理器。paper_open按资料id打开私有PDF，复用现有xdg-open，不向模型传文件路径。
- [x] 小卡片可见拖放说明、打开原件按钮；打开失败显示可重试信息。保持默认要求无需填写。
- [x] 前端与Rust回归、隔离原生合成PDF导入事件与原件打开验证；普通构建同步桌面原入口和试用入口，保留旧程序，不强退日常实例。

范围以外：原生PDF模型协议、自动长文工具、付费模型验证。

复核修正：系统阅读器可能启动成功后退出失败，后台观察退出状态并按资料id回传失败提示；重试清理对应提示，不等待阅读器关闭。恢复附件与导入互斥，选择库中其他论文清除旧恢复锁，迟到查询不覆盖新附件。

验收：前端215、Rust240/2忽略、Svelte0/0、原生合成DOM/IPC闭环及普通构建通过。隔离桌面截图透明异常未计为外观通过。桌面原入口与试用入口已同步，详见docs/validation/2026-11-09-paper-drop-and-original.md。
