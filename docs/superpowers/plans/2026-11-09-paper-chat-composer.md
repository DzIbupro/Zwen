# 将论文阅读收进对话输入区

用户已确认论文分析可用，要求取消独立侧栏板块，改为输入框上方的小功能入口。本次沿feat/paper-analysis-v2实施，不合并主分支、不新增真实模型调用。

1. 输入区“论文阅读”按钮启用既有能力；选择PDF后显示可移除附件，点击普通发送按钮发起分析。空输入使用内置阅读要求，输入文字作为本轮问题。可选要求默认折叠；已有论文/旧记录仅保留在可选资料菜单。回答、停止、历史、追问、收藏和导出沿用对话。
2. 上传草稿保存在会话本地状态；失败保留，成功发送后由绑定的论文会话承接。新PDF开启新的论文会话；退出已有论文阅读使用新普通会话，避免仅改外观却继续发送原文。截图保持隔离。
3. 移除独立论文导航、页面与孤立的页面测试。测试默认直接发送、自定义问题、导航无论文入口、附件移除、失败保留与迟到导入结果。
4. 主界面选词提示接收onDiscard并增加带可访问名称的×按钮；沿用原生acknowledge关闭操作条，保留草稿。测试候选、错误提示与处理中状态。
5. 前端及相关原生回归、隔离桌面PDF→对话→追问/停止、选择提示关闭验证；普通构建更新论文试用入口，保留日常程序。记录真实验证边界。
