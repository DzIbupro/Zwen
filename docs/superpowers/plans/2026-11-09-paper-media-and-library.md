# 论文后续：页图补读与资料列表

用户已确认对话内论文流程可用，并授权继续未完成工作。本轮继续feat/paper-analysis-v2，不调用真实模型、不合并主分支。

## 本轮实现

1. 阅读选项增加可选“页图补读”，沿用已配置的图片模型、原生PDF私有副本、Poppler和现有图像消息序列化。不安装OCR引擎或常驻服务，不默认更换文字模型。所选范围最多8页，逐页对应物理页标记，输出仍直接Markdown。扫描件可在所选页图可用时分析；无图片模型时明确说明。
2. 渲染放入现有原生任务worker，复用现有停止/保存/失败生命周期，不能在启动锁内渲染而阻塞取消。图片通过内存管道取得，不保存额外页图；单页与总量均有界，失败不能冒充已读图像。
3. v2资料库升级为元数据索引，升级前生成私有SQLite一致快照，事务迁移保留所有来源、原件和会话。列表按游标分页，恢复草稿按id查询，不再加载全文或受最近1000条限制。
4. 小卡片保持简洁，图像选项/加载更多都在原有折叠入口中。真实模型和实际页图发送方式可见；追问重用开始时保存的范围与模式。
5. 测试默认纯文字不变、扫描页仅图像路径、范围/页数限制、无模型、取消、请求图片序列化、旧库迁移和分页/按id恢复。原生合成服务验收、普通构建与试用入口更新。

## 尚未包含

原生PDF附件协议、自动agent式长文读取、独立本地OCR与真实图片模型质量验收仍是后续项。本轮不恢复旧的分批JSON流水线。
