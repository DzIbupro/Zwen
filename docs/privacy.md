# 数据与隐私

Zwen 是本机保存资料、连接用户自选模型服务的桌面客户端。它不提供托管模型，也不能替代模型服务商的数据政策。

## 哪些数据会发送

| 操作 | 模型请求中的内容 |
| --- | --- |
| 普通聊天 | 当前问题、必要的近期会话上下文。 |
| 截图提问 | 当前问题与选中的截图，由配置的图片模型处理。 |
| 论文分析及追问 | 保存页范围的整页图、辅助文字、阅读要求、可选研究方向及必要对话上下文。仅文字模式不发送页图。 |
| AI 整理 | 选中笔记的标题与有界正文，以及最多 80 项未锁定的已有主题、栏目名称，帮助复用分类。 |

导入 PDF、浏览历史、编辑笔记及本地绘制知识网络不调用模型。自动整理是需要用户开启的例外：开启后，新收藏会触发整理请求。请根据材料的保密要求选择模型服务和自动整理设置。

模型调用会使用服务密钥完成鉴权。应用保存的密钥位于系统 Secret Service 钥匙环，或由启动环境读取；普通设置数据库不保存密钥值，界面也不读回密钥。钥匙环不可用时不会伪装保存成功。

## 本机保存

应用数据包含对话、草稿、PDF 原件、页图、截图、Markdown 笔记和数据库索引。它们是本机文件，并非由应用额外加密的保险库；有权访问当前系统账户或备份的人可能读取这些内容。

请保护账户与磁盘、正常退出后备份完整数据目录，勿把该目录放入公开同步或 Git 提交范围。导出的 Markdown 和附带图像也可能含私人内容，分享前需要自行检查。

## 公开反馈

反馈优先使用合成样例。删除日志、截图或文件中的密钥、私人服务地址、用户名、绝对路径、对话正文及论文内容后再公开。

`.gitignore` 只帮助忽略常见本地文件，不是安全边界；使用 `git add -f` 或添加其他文件名仍可能泄露数据。提交前应查看差异，并使用密钥扫描工具检查。
